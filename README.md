# Patel Control Panel

A smart and interactive Store Management System built with Python, Tkinter, and MySQL. It brings product management, inventory control, shopping cart operations, and automated bill generation together in one application.

##  Features

- Admin panel for managing store products
- Add, update, and manage product information
- Product inventory management
- Shopping cart functionality
- Automatic bill calculation
- Customer bill generation
- MySQL database integration
- User-friendly Tkinter graphical interface

##  Technologies Used

- Python
- Tkinter
- MySQL
- MySQL Connector/Python
- Python-docx
